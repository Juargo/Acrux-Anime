# i18n: Spanish and English with a selector (#43)

Objective: the web app in Spanish and English, browser language by default, a language selector in Perfil, and the choice stored in the account.
Branch: `feat/i18n`. Delivery: single-pr (stakeholder, 2026-11-07). Test runner: vitest (`pnpm --filter @acrux/web test`, `pnpm --filter @acrux/api test`).

## Specs

- **S1** (issue #43, tasks): "i18next + react-i18next con detección del idioma del navegador". If the browser language is neither Spanish nor English, use English (ADR-0010: "El idioma se toma del dispositivo y se usa inglés por defecto si el idioma no es ninguno de los dos").
- **S2** (issue #43): "Textos en `packages/i18n`". Adding a language needs no logic changes (RNF-71: "Agregar un idioma no requiere cambios en la lógica.").
- **S3** (issue #43): "Selector de idioma en el perfil (RF-71)".
- **S4** (stakeholder, 2026-11-07): the language is stored in the account ("En la cuenta"). `locale` becomes optional: null means "use the browser language". PATCH /me can change it. Existing profiles move to null because nobody chose "es".
- **S5** (issue #43): "Errores de la API traducidos por su `code` (ADR-0023)".
- **S6** (issue #43, acceptance):
  ```gherkin
  # language: es
  @CA-RF71-01
  Escenario: Cambiar el idioma
    Dado que la app está en español
    Cuando elijo inglés en mi perfil
    Entonces toda la interfaz se muestra en inglés y la preferencia se mantiene
  ```
- **S7** (RF-70): "La app está en español e inglés y usa el idioma del navegador por defecto." All web UI text, aria-labels and `document.title` go through translations, and `<html lang>` follows the active language.
- Assumption: the API crawler page and the OG image (`apps/api/src/modules/public-profile/og.ts`) and the static PWA manifest stay in Spanish; they are outside the web UI. The landing (`apps/landing`) keeps its own copy.
